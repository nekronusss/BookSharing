# BookSharing — фронтенд

React-интерфейс каталога, профиля и обменов книгами. Полная инструкция с PostgreSQL и Spring Boot находится в [основном README](../README.md).

**React 18 · Vite 5 · React Router 6 · Axios · Tailwind CSS 3**

## Запуск

Понадобятся Node.js 22 или 24 с npm. Из этой папки:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:4200/?demo=1` для автономной демонстрации без сервера. Алина и Марк переключаются в верхней полосе; локальные изменения сохраняются в браузере. Сценарий показа: [DEMO.md](../docs/DEMO.md). Если порт занят, смотрите адрес в терминале Vite.

## Подключение к API

Переключитесь кнопкой «К реальному API» либо откройте `/?demo=0`. По умолчанию [API-клиент](src/services/api.js) использует `/api`; [Vite](vite.config.js) перенаправляет запросы на `http://localhost:8080`, удаляя префикс. Ошибка сервера не включает демо автоматически.

Чтобы изменить адрес, создайте `frontend/.env.local`:

```dotenv
VITE_API_URL=http://localhost:8080
```

Перезапустите Vite или пересоберите сайт. Переменные `VITE_*` видны браузеру: секреты в них не размещают. В production dev-proxy не работает — маршрут `/api` нужно настроить на веб-сервере либо указать полный адрес API при сборке и разрешить origin через `CORS_ALLOWED_ORIGINS`. Изображения `/uploads/` должны быть доступны через тот же адрес API.

## Сборка и проверки

```sh
npm test
npm run format:check
npm run build
npm run preview
```

`npm test` запускает сценарии демо и React-компонентов, `npm run format` применяет форматирование Prettier. Тесты не заменяют проверку камеры, вёрстки и доступности в настоящем браузере.

`dist/` содержит статические файлы. `preview` позволяет локально проверить сборку; для реального режима API запускается отдельно. Для публичного размещения нужны HTTPS, корректный `VITE_API_URL`, CORS на API и возврат `index.html` для маршрутов React Router. Сборка контейнера описана в [README](../README.md).

## Основные файлы

| Путь | Назначение |
| --- | --- |
| `src/App.jsx` | Маршруты, обработка ошибок и ленивое подключение страниц |
| `src/pages/` | Каталог, книга, обмены, профиль, вход и регистрация |
| `src/components/` | Навигация, карточки, формы и QR-коды |
| `src/context/AuthContext.jsx` | Состояние авторизации |
| `src/services/api.js` | Запросы Axios и JWT-заголовок |
| `src/services/demo.js` | Автономные сценарии с локальными данными |
| `src/index.css` | Стили и Tailwind |
| `tests/` | Тесты сценариев и React-компонентов |

Токен хранится в `localStorage`; при `401` вне входа/регистрации клиент очищает сессию и уведомляет интерфейс. Демо использует отдельные ключи хранения. Ограничения перед публичным запуском: [RELEASE.md](../docs/RELEASE.md).
